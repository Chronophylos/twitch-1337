Commands · Execution

Capacity for commands that run in the background, such as !news or !aktien. An invocation runs when an active slot is free at every level; otherwise it waits in a first-in, first-out pending queue, and when the queue is full chat gets "zu viel zu tun". Changes apply immediately: raising a limit starts queued work right away, lowering one never stops a running command or drops a queued one. !bash also keeps its own concurrency limit.
