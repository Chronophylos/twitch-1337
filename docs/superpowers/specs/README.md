# Design archive

Historical design docs, one per feature, accurate **as of the date in the filename**
and not maintained since. Several are superseded by later specs on the same topic
(e.g. the AI-memory chain: `ai-memory-rework` → `-v2` → `ai-settings-hoist` →
`config-to-settings-final-migration`). Many predate the `crates/` workspace split
and name `src/…` paths that no longer exist.

Read them for *why* a thing was built the way it was. Do not implement against them.

Current architecture lives in `AGENTS.md`, domain language in `CONTEXT.md`, and
decisions of record in `docs/adr/`.
