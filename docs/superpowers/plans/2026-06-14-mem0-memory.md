# mem0 Memory Replacement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the custom v2 AI memory subsystem (markdown SOUL/LORE/user/state files, fenced prompt injection, model write-tools, nightly dreamer, transcripts, dashboard editor) with mem0 over REST: semantic search before each `!ai` turn, fire-and-forget extraction after, one `forget` tool.

**Architecture:** A thin `reqwest` mem0 client behind a `MemoryApi` trait (fakeable in tests) lives in `crates/core/src/ai/mem0.rs`. The `!ai` turn searches mem0 (two scoped queries, deduped) into a "What you remember" block, runs the agent loop with `forget` + existing web/doener tools, then spawns an `add()`. Persona stays in `prompts/system.md`. The entire `ai/memory/` tree, the dreamer, and transcripts are deleted.

**Tech Stack:** Rust, reqwest (rustls/musl), serde, async-trait, axum + askama (dashboard), wiremock (tests). mem0 OSS v2.0 REST server (separate container, built in CI).

**Ponytail deltas from the spec** (deliberate simplifications, flagged inline):
- **No settings schema-version bump / no removal-migration.** serde drops unknown RON fields, so deleting `ai.memory`/`ai.dreamer` from `SettingsOverrides` leaves old `settings.ron` files parsing fine. `SCHEMA_VERSION` stays `4`.
- **`AiMemoryV2` struct + `build_ai_memory_v2` are deleted**, not repurposed. `AiCommand` carries `mem0: Option<Arc<dyn MemoryApi>>` and reads `max_turn_rounds`/`timeout`/`search_limit` live from the per-turn settings snapshot (matching how `model` is already read).
- **`AiBehavior.max_writes_per_turn` is left in place** (now inert) with a `// ponytail:` comment — removing it touches the struct, overrides, resolve, validate, the behavior card, and the save form to delete one integer. Add removal when someone trims the behavior card.
- **One `add()` method, no `infer` flag.** mem0 extracts by default; migration passes the file body as one user message and lets mem0 distil it.

//! mem0 REST client. Four endpoints, behind a trait so tests fake it.
//!
//! OSS v2.0 endpoints (no `/v1/` prefix), auth via `X-API-Key`:
//! `POST /search`, `POST /memories`, `GET /memories?user_id=`,
//! `DELETE /memories?user_id=`, `DELETE /memories/{id}`.

use std::time::Duration;

use async_trait::async_trait;
use eyre::{Result, eyre};
use llm::{ToolCall, ToolDefinition, ToolResultMessage};
use secrecy::{ExposeSecret as _, SecretString};
use serde::{Deserialize, Serialize};

pub const FORGET_TOOL_NAME: &str = "forget";

/// Which scope a `search` filters on. mem0 stores both ids on every memory and
/// filters by subset-match, so `Agent` is channel-wide and `User` is a subset.
#[derive(Debug, Clone, Copy)]
pub enum Scope<'a> {
    User(&'a str),
    Agent(&'a str),
}

/// One memory returned by search/list.
#[derive(Debug, Clone, Deserialize)]
pub struct MemoryHit {
    pub id: String,
    #[serde(default)]
    pub memory: String,
}

/// A chat message handed to `add` for extraction.
#[derive(Debug, Clone, Serialize)]
pub struct TurnMessage {
    pub role: String,
    pub content: String,
}

#[async_trait]
pub trait MemoryApi: Send + Sync {
    async fn search(&self, query: &str, scope: Scope<'_>) -> Result<Vec<MemoryHit>>;
    async fn add(
        &self,
        messages: &[TurnMessage],
        user_id: &str,
        agent_id: &str,
        metadata: serde_json::Value,
    ) -> Result<()>;
    async fn delete_user(&self, user_id: &str) -> Result<()>;
    async fn delete_one(&self, memory_id: &str) -> Result<()>;
    async fn list_user(&self, user_id: &str) -> Result<Vec<MemoryHit>>;
}

pub struct Mem0Client {
    http: reqwest::Client,
    base_url: String,
    api_key: SecretString,
    limit: usize,
}

impl Mem0Client {
    /// `base_url` is the mem0 server root (no trailing slash needed).
    pub fn new(base_url: &str, api_key: SecretString, timeout: Duration, limit: usize) -> Result<Self> {
        let http = reqwest::Client::builder()
            .user_agent(crate::APP_USER_AGENT)
            .timeout(timeout)
            .build()?;
        Ok(Self { http, base_url: base_url.trim_end_matches('/').to_owned(), api_key, limit })
    }
}

#[derive(Deserialize)]
struct SearchResponse {
    #[serde(default)]
    results: Vec<MemoryHit>,
}

#[async_trait]
impl MemoryApi for Mem0Client {
    async fn search(&self, query: &str, scope: Scope<'_>) -> Result<Vec<MemoryHit>> {
        let mut body = serde_json::json!({ "query": query, "limit": self.limit });
        match scope {
            Scope::User(id) => body["user_id"] = id.into(),
            Scope::Agent(id) => body["agent_id"] = id.into(),
        }
        let resp = self
            .http
            .post(format!("{}/search", self.base_url))
            .header("X-API-Key", self.api_key.expose_secret())
            .json(&body)
            .send()
            .await?;
        if !resp.status().is_success() {
            return Err(eyre!("mem0 search {}", resp.status()));
        }
        Ok(resp.json::<SearchResponse>().await?.results)
    }

    async fn add(
        &self,
        messages: &[TurnMessage],
        user_id: &str,
        agent_id: &str,
        metadata: serde_json::Value,
    ) -> Result<()> {
        let body = serde_json::json!({
            "messages": messages,
            "user_id": user_id,
            "agent_id": agent_id,
            "metadata": metadata,
        });
        let resp = self
            .http
            .post(format!("{}/memories", self.base_url))
            .header("X-API-Key", self.api_key.expose_secret())
            .json(&body)
            .send()
            .await?;
        if !resp.status().is_success() {
            return Err(eyre!("mem0 add {}", resp.status()));
        }
        Ok(())
    }

    async fn delete_user(&self, user_id: &str) -> Result<()> {
        let resp = self
            .http
            .delete(format!("{}/memories", self.base_url))
            .query(&[("user_id", user_id)])
            .header("X-API-Key", self.api_key.expose_secret())
            .send()
            .await?;
        if !resp.status().is_success() {
            return Err(eyre!("mem0 delete_user {}", resp.status()));
        }
        Ok(())
    }

    async fn delete_one(&self, memory_id: &str) -> Result<()> {
        let resp = self
            .http
            .delete(format!("{}/memories/{memory_id}", self.base_url))
            .header("X-API-Key", self.api_key.expose_secret())
            .send()
            .await?;
        if !resp.status().is_success() {
            return Err(eyre!("mem0 delete_one {}", resp.status()));
        }
        Ok(())
    }

    async fn list_user(&self, user_id: &str) -> Result<Vec<MemoryHit>> {
        let resp = self
            .http
            .get(format!("{}/memories", self.base_url))
            .query(&[("user_id", user_id)])
            .header("X-API-Key", self.api_key.expose_secret())
            .send()
            .await?;
        if !resp.status().is_success() {
            return Err(eyre!("mem0 list {}", resp.status()));
        }
        // OSS returns a bare array for GET /memories.
        Ok(resp.json::<Vec<MemoryHit>>().await?)
    }
}

            Use only when they explicitly ask you to forget them. Takes no arguments."
            .into(),
        parameters: serde_json::json!({ "type": "object", "properties": {} }),
    }
}

/// Returns the joined `## Recent chat (#login)` sections, ai/primary ordered so
/// the invoking channel's block renders first. Empty when no history.
pub async fn render_recent_chat(opts: RecentChatOpts) -> String {
    let primary = render_recent_section(opts.primary_history.as_ref(), &opts.primary_login,
        RECENT_CHAT_PRIMARY_BYTES, &opts.bot_login, &opts.persona_name).await;
    let ai = match (opts.ai_channel_history.as_ref(), opts.ai_channel_login.as_ref()) {
        (Some(b), Some(l)) => render_recent_section(Some(b), l,
            RECENT_CHAT_AI_CHANNEL_BYTES, &opts.bot_login, &opts.persona_name).await,

async fn migrate_memories_to_mem0(
    m: &dyn twitch_1337::ai::mem0::MemoryApi,
    data_dir: &std::path::Path,
    channel: &str,
) -> Result<()> {
    use twitch_1337::ai::mem0::TurnMessage;
    let strip_fm = |raw: &str| raw.split_once("\n---\n").map(|(_, b)| b.to_string()).unwrap_or_else(|| raw.to_string());
    let one = |body: String| vec![TurnMessage { role: "user".into(), content: body }];

    if let Ok(mut rd) = tokio::fs::read_dir(&users_dir).await {
        while let Some(ent) = rd.next_entry().await? {
            let path = ent.path();
            let Some(id) = path.file_stem().and_then(|s| s.to_str()) else { continue };
            let body = strip_fm(&tokio::fs::read_to_string(&path).await?);
            if body.trim().is_empty() { continue; }
            m.add(&one(body), id, channel, serde_json::json!({})).await?;

        }

    Ok(())
